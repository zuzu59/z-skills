# Markdown

- When writting Makrdown file, use the [CommonMark specification].
- Line must never be longer than 80 chars.
- Use footnote for links.
- Use `#` for title, no `---` or `===`.
- Use UK english.
- Don't use emoji.
- List are better with `-` than `*`.

[CommonMark specification]: https://spec.commonmark.org
