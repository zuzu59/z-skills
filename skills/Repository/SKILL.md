# Repository

The repository of the project must contains up to date:
- README.md
  Add a README file to the repository to tell other people why this project is useful, what they can do with this project, and how they can use it.
- LICENSE.md
  Add a MIT license. The copyright line should be:   `Copyright (c) [year] EPFL ISAS-FSD [fullname]`
- CHANGELOG.md
  https://keepachangelog.com/
  Add a changelog which contains a curated, chronologically ordered list of notable changes for each version of this project. 
- TODO.md
  Keep a up-to-date TODO.md file with what's done and what's is to be done.


The repository of the project may contain

- CONTRIBUTING.md
  A file communicates how people should contribute to this project.
- CODE_OF_CONDUCT.md
  A CODE_OF_CONDUCT file defines standards for how to engage in a community.
- SECURITY.md
  Security Policy + Ways to report
